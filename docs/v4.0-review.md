## 8. Sanity glance — unchanged code paths

These were scanned to confirm v4.0 didn't accidentally break v3.7 behavior:

* `ClockViewModel.kt` (92 LOC) — unchanged: still drives AUTO/MANUAL via a
  transient `MutableStateFlow`, seeds manual mode from `Calendar.getInstance()`,
  wraps modulo 12h cycle. No public-API change.
* `ClockPreferencesRepository.kt` (53 LOC) — unchanged: 4 DataStore-backed
  preferences (`time_format`, `language`, `show_seconds`, `voice_gender`).
* `ClockUiState.kt` (50 LOC) — unchanged enums + data class.
* `util/SmartTtsManager.kt`, `util/PreRecordedTtsPlayer.kt`,
  `util/TimeSpeech.kt`, `util/TtsManager.kt` — unchanged from v3.7.x.
  Quiz screen reuses `SmartTtsManager.speakTime(…)` directly; the contract
  matches the digital-card speaker on the clock screen.
* `presentation/settings/SettingsScreen.kt` — still wired through the nav
  graph (`Routes.SETTINGS = "settings"`) even though it isn't reachable
  from the new quiz/clock surfaces. Not a regression — it was already
  unreachable from the v3.7 root.
