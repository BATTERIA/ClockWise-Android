1. 产品定位 Product Positioning

ClockWise — 一款专为4-10岁儿童设计的时钟学习应用，通过互动动画、游戏化练习和故事驱动，让孩子在玩乐中掌握时间概念。

📱 Platform

Android (Tablet优先，Phone兼容)

🌍 Language

Chinese + English 双语 (默认English)

👶 Target

4-10岁儿童及家长/教师

🎯 Goal

让每个孩子轻松学会看时钟

2. 学习内容体系 Curriculum

⏰ 时钟类型认知

📚 分阶段课程 L1-L4

Level内容目标年龄
L1 整点认识1-12点整4-5岁
L2 半点半点、一刻5-6岁
L3 任意分钟精确到分钟7-8岁
L4 时区世界时间、AM/PM、24h9-10岁

🔊 语音引导系统

  • Android TTS (TextToSpeech) 引擎驱动

🎮 渐进式界面 Progressive UI

根据学习进度逐步解锁界面元素，避免信息过载。低Level只显示核心功能，高Level解锁高级工具。

10. 项目定位 Project Values

核心理念：开源、免费、纯粋为了教育。不以盈利为目的，让每个孩子都能用上优质的学习工具。
  • ✅ 100% 免费 — 所有功能永久免费
  • 🚫 无广告 — 绝不向儿童展示广告
  • 🚫 无内购 — 不设任何付费解锁
  • ☕️ 可选打赏 — 未来可能提供 Buy Me a Coffee 供喜欢项目的用户支持
  • 🔓 开源 — 代码公开，欢迎贡献
  • ♿ 无障碍优先 — 所有无障碍功能有同等优先级
  • 🔒 COPPA合规 — 严格遵守儿童隐私保护法规，不收集个人数据

11. 无障碍支持 Accessibility

  • TalkBack全覆盖 — 所有界面元素有语义描述
  • 高对比度模式 — 可选高对比度配色方案
  • 大字体支持 — 尊重系统字体缩放
  • 色盲友好 — 不依赖颜色传递关键信息
  • 大触摸区域 — 最小48dp×48dp触摸目标
