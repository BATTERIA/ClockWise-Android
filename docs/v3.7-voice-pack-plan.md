# v3.7.0 — Pre-Recorded Voice Pack 方案

**问题**：v3.6.7 用 Android `TextToSpeech` 报时，在小米/华为/魅族等设备上经常翻车（没装 Google TTS、`attributionTag` 警告、童声音色机械、后台被杀）。给孩子听的时钟，体验拉胯。

**结论**：完全甩开手机 TTS 引擎，改用**云端预渲染的全句童声音频包**，运行时由 `MediaPlayer` 直接播放。

---

## 方案总览

```
┌─────────────────────────────────────────────────────────────┐
│  app/src/main/assets/voice/                                 │
│    ├── girl/                  ←— 👧 小姐姐 (XiaoyiNeural)   │
│    │   ├── zh/                                              │
│    │   │   ├── am/0100.ogg .. 1259.ogg   (720)              │
│    │   │   ├── pm/0100.ogg .. 1259.ogg   (720)              │
│    │   │   └── manual/0100.ogg .. 1259.ogg (720)            │
│    │   └── en/                                              │
│    │       ├── am/    (720)                                 │
│    │       ├── pm/    (720)                                 │
│    │       └── manual/(720)                                 │
│    └── boy/                   ←— 👦 小哥哥 (YunxiaNeural)   │
│        └── (同样结构)                                       │
└─────────────────────────────────────────────────────────────┘
8,640 OGG/Opus 文件，每个 ~5–9 KB，总 75 MB
```

**3 个文案模板**：

| 桶  | 中文模板 | 英文模板 | 何时用 |
|-----|---------|---------|--------|
| `am`| 现在是上午 X 点 Y 分 | It's X:YY AM. | 自动模式 + 12h + AM |
| `pm`| 现在是下午 X 点 Y 分 | It's X:YY PM. | 自动模式 + 12h + PM |
| `manual`| X 点 Y 分（无前缀） | X o'clock / X:YY（无 AM/PM） | 手动调整表盘时 |

整点用 "X 点整" / "X o'clock"，避免说"零分"。

## 选型

**TTS 引擎**：Microsoft Edge TTS（`edge-tts` Python 包）
- 免费、无 API key
- 神经网络童声，远超系统 TTS
- 一次性服务器侧渲染，APK 内不依赖任何运行时网络

**音色**：
| 角色 | 中文 voice | 英文 voice | 语速 |
|------|-----------|-----------|------|
| 👧 Girl | `zh-CN-XiaoyiNeural` (卡通活泼) | `en-US-AnaNeural` (童声) | −8% |
| 👦 Boy  | `zh-CN-YunxiaNeural` (童声可爱) | `en-US-AndrewMultilingualNeural` (温暖) | −5% |

**编码**：OGG/Opus 24 kbps mono, voip-mode（语音优化）
- 单文件 ~5–9 KB（vs 原 MP3 ~15–25 KB，省 56%）
- Android `MediaPlayer` 原生支持，无第三方解码

**APK 配置**：`androidResources { noCompress.add("ogg") }`
- 阻止 aapt 二次压缩已经是 Opus 的资源（CPU 浪费、几乎无收益）

## 运行时架构

```
ClockScreen 用户点 🔊
   │
   ▼
SmartTtsManager.speakTime(hour, minute, isPm, language, gender, mode, …)
   │
   ├─► PreRecordedTtsPlayer.playTime(…)
   │        │
   │        ├─ 拼路径: voice/<gender>/<lang>/<period>/HHMM.ogg
   │        │   period = manual | am | pm
   │        │
   │        ├─ 资源不存在 / 24h 模式 / 显示秒 → 返回 false
   │        │
   │        └─ 资源存在 → MediaPlayer.start()  ✅
   │
   └─► （未命中时）TtsManager.speak(…)  系统 TTS 兜底（仅 24h / showSeconds）
```

**关键文件**：
- `util/PreRecordedTtsPlayer.kt` — 核心 asset 播放器（MediaPlayer 包装）
- `util/SmartTtsManager.kt` — pre-rec → system-tts 路由层
- `util/TtsManager.kt` — 旧引擎（保留作为 24h/秒模式 fallback）

## 覆盖范围

| 场景 | 走预录? | 走系统 TTS? |
|------|--------|-------------|
| 12h + 不显示秒 + 自动模式 | ✅ 用 am/pm 桶 | — |
| 12h + 不显示秒 + 手动模式 | ✅ 用 manual 桶 | — |
| 12h + 显示秒 | ❌ | ✅ |
| 24h | ❌ | ✅ |

> 显示秒 / 24h 模式继续走系统 TTS，因为：
> a) 这俩组合不是默认体验（默认 12h, no-seconds）
> b) 全量预录会让 APK 增量翻倍（再加 22+ MB）
> c) MIUI 玩家通常会切到默认模式，主路径已经完全规避了系统 TTS 的问题

## 生成流水线

构建脚本：`/home/azureuser/.openclaw/workspace/clock-poc/generate_voice_pack.py`

用法：
```bash
python3 generate_voice_pack.py \
    --output voice-pack \
    --voices girl,boy \
    --concurrency 14
```

- 并发 14（edge-tts 网络瓶颈，再大也快不了）
- 已存在的 ogg 自动跳过（增量重跑）
- 通过 ffmpeg 转 Opus 24k

跑一次完整 girl+boy（8640 文件）≈ 25 分钟。

新增音色：在 `VOICES = {...}` 加一项，重跑脚本。

## 已知取舍

1. **APK 从 10 MB → 76 MB**：主要是 75 MB voice pack。这是 Bluey-friendly 童声的代价；想缩小可以只内置一个音色（−24MB）或砍 manual 桶（−22MB）。
2. **24h / 秒模式仍依赖系统 TTS**：见上面"覆盖范围"。
3. **音色固定**：edge-tts 神经网络声音是同一个人，所有时刻语调一致 — 这是优点（零拼接接缝），但也意味着没法用真人录音的个性化情感。

## 后续可优化

- 加 `assets/voice/<gender>/special/*.ogg`：节日/生日/起床/睡觉的特殊问候

- 24h 模式扩展：再渲一套 24h 全句（约 +22 MB）
