① 本次改动概览

v4.2 变更点：

  1. 删除所有 「→」 箭头 — 答错 FAB 的 ArrowForward 图标和文案里的 → 都干掉了，FAB 本身就是响应区。
  2. 全屏弹性动画 — Material 3 抠了个 Spring 调同子，顶部语言 / 时钟 / 问题 / 3 个选项 / 结果横幅 / 返回键，出现时都以 spring(DampingRatioMediumBouncy, StiffnessLow) “点 — 跳 — 那么一下”出来，消失时轻轻缩小深取。
  3. 语言字符 中 / EN 在切换时会护身趋缩放动画。
  4. 题目切换时表盘也 spring出现，三个选项 stagger 70 ms 逐个跳出。

其他业务逻辑不变。详细的动画参数看 QuizScreen.kt 里的 bounceEnter / softExit / springFloat 三个顶级常量。

② 当前游戏逻辑（v4.0，本次不改）

题目生成

  • 每题随机出一个时钟时间：小时 1–12，分钟从「允许集合」里随机抽一个。
  • 表盘静态显示该时间，下面 3 个选项：1 正 + 2 错。
  • 干扰项策略：
    • ① 差一个小时（最常见的孩子错误，例如把 3:00 看成 2:00 或 4:00）。
    • ② 同小时、不同分钟（仅在难度允许多种分钟时启用）。

难度阶梯（按 连续答对 自动升级）

Lv 1

整点

连对 0–2 题

minute ∈ {00}

例：3:00 / 7:00

Lv 2

整点 + 半点

连对 3–5 题

minute ∈ {00, 30}

例：3:00 / 7:30

Lv 3

整点 + 一刻

连对 ≥ 6 题

minute ∈ {00, 15, 30, 45}

例：3:15 / 9:45

⚠️ 答错时 streak 归零，自动退回到「整点」难度，保护信心。

答题流程

  1. 题目出现，等待孩子点选项。
  2. 点选项后立即「揭晓」：选中按钮放大 1.05× 弹一下，正确变绿 / 错误变红。
  3. 答对：显示绿色 ✓ banner，1.4 秒后自动出下一题。
  4. 答错：显示蓝色「下一题」FAB，由孩子自己点一下才进下一题（给一秒钟冷静）。
  5. 顶部喇叭按钮随时可重听题目（用 v3.7 的童声音包，跟着语言/12-24h/音色走）。
