1. Product Positioning

ClockWise — a clock-learning app designed specifically for children ages 4–10. Interactive animations, gamified practice, and story-driven content help kids master the concept of time while they play.

📱 Platform

Android (tablet-first, phone-compatible)

🌍 Language

Chinese + English bilingual (English by default)

👶 Target

Children ages 4–10, plus their parents and teachers

🎯 Goal

Make it easy for every kid to learn to read a clock

History and craftsmanship

📚 Staged curriculum (L1–L4)

LevelContentTarget age
L1 — HourRecognize 1–12 o'clock on the hour4–5
L2 — Half-hourHalf-hours and quarters5–6
L3 — Any minuteMinute-level precision7–8

🔊 Voice-guidance system

  • Powered by Android TTS (TextToSpeech)
  • Action guidance — tell the child what to do next
  • Read-aloud — speak the question content
  • Feedback — encouragement and correction

🎮 Progressive UI

UI elements unlock gradually based on learning progress, avoiding information overload. Lower levels expose only core features; higher levels unlock advanced tools.

📅 Time & calendar concepts

  • Days of the week (Monday–Sunday)
  • Months and seasons
  • Units of time (second → minute → hour → day → week → month → year)
  • Temporal ordering words (before, after, earlier, later)
  • Animated teaching of basic time concepts

🌍 Timezone module

  • Interactive world map — tap a city to see local time
  • Day/night animation — Earth's rotation and the day/night cycle
  • Real-life scenarios — "It's 8am in Beijing — what time is it in New York?"

3. Quiz System

9 question types

1. Read the clock

Look at the hands and answer the time

2. Set the clock

Drag the hands to set a given time

3. Time matching

Match-up / connect-the-pairs

4. Time ordering

Arrange events in chronological order

5. Time arithmetic

"What time will it be in 30 minutes?"

6. Multiple choice

Pick one of several options

7. Fill-in-the-blank

Type the correct time

8. True/false

Right or wrong

9. Scenario

Apply time to everyday situations

Smart features: auto-generation logic (questions adapt to the current level) + spaced-repetition algorithm (prioritize the kid's weak spots).

5. Bilingual Support

  • UI and voice swap together (one-tap toggle between Chinese and English)
  • Multiple time expressions:
    • English: "half past three", "quarter to five", "3:30 PM"
    • Chinese: "三点半", "差一刻五点", "下午3:30"
  • Internationalization via Android Resources (strings.xml)
  • TTS voice automatically matches the current language

10. Project Values

Core principle: open-source, free, purely for education. Not driven by profit — every child deserves a quality learning tool.
  • ✅ 100% free — every feature, forever
  • 🚫 No ads — never show ads to kids
  • 🚫 No in-app purchases — nothing locked behind a paywall
  • 🔓 Open source — code in the open, contributions welcome
  • ♿ Accessibility-first — every accessibility feature is treated as a first-class priority
  • 🔒 COPPA-compliant — strict adherence to child-privacy regulations; no personal data collected

11. Accessibility

  • Full TalkBack coverage — every UI element has a semantic description
  • High-contrast mode — optional high-contrast color scheme
  • Large text — respects the system font-scale setting
  • Colorblind-friendly — never relies on color alone to convey key information
  • Large touch targets — minimum 48dp × 48dp

12. Culture & Timezone

🌏 Time across world cultures

🗣️ Multilingual time expressions

  • Compare how Chinese and English express the same time
  • Fun translation mini-games
